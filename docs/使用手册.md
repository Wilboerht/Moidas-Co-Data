## 1. 系统简介

### 1.1 系统能做什么

Co-data 是一个“采集—筛选—人工审核—合作跟进—线索转化—导出”的达人运营工作台。

主要能力：

- 按平台、垂类、关键词创建采集轮次；
- 自动搜索笔记、识别作者、补全达人资料并去重；
- 在达人库中筛选、审核、批量标注和导出；
- 对已采用达人进行合作跟进，记录状态、备注、附件和作品；
- 导入客户/历史线索，校验账号并转为达人；
- 管理关键词、成员账号和团队权限。

当前支持的平台：

- 小红书
- 抖音
- B 站
- 知乎
- Instagram

当前可选的数据服务商：

- DataFlow
- Rnote
- EveryInfra
- TikHub
- JustOneAPI
- SocialDataX
- RedFoxHub

不同平台可选的服务商不同，价格也会变化，以“新建采集”和“设置”页面显示为准。

### 1.2 标准工作流程

```text
创建关键词与采集轮次
        ↓
系统搜索笔记并补全达人资料
        ↓
达人库审核：待审核 → 备选 / 已采用 / 未采用
        ↓
已采用达人进入合作跟进
        ↓
记录合作状态、沟通备注、合同附件、合作作品
        ↓
导入线索 → 匹配/校验 → 转为达人
        ↓
导出达人表、线索表或合作档案
```

### 1.3 核心概念

| 术语 | 含义 |
|---|---|
| 平台 | 数据来源平台，如小红书、抖音 |
| 服务商 | 实际提供达人数据的数据服务公司 |
| 采集轮次 | 一次采集批次，包含一个平台、一组关键词和采集范围 |
| 运行记录 | 一次真正调用接口抓取数据的执行；同一轮次可重跑，产生新的运行记录 |
| 垂类 | 轮次的业务归类，如护肤、咖啡、母婴 |
| 关键词 | 采集用的搜索词 |
| 达人 | 平台账号的正式资料，跨轮次共享 |
| 达人-轮次记录 | 某位达人在某一轮次中的审核状态、备注、样本数据等 |
| 采用状态 | 每轮审核结果：待处理、备选、已采用、未采用 |
| 合作状态 | 达人主档上的合作阶段，跨轮次共享 |
| 合作记录 | 一次独立合作，包含状态、备注、附件、作品和时间线 |
| 跟进人 | 达人当前的责任人；只是责任标记，不限制其他人编辑 |
| 线索 | 待核实或待转化的达人资源，与达人库分开管理 |
| 平台账号 | 用户可见的账号，如小红书号、微博号 |
| 平台用户 ID | 采集服务商使用的内部账号 ID，不等于平台账号 |
| 主页链接 | 达人平台主页地址 |
| 账号校验 | 线索账号的校验结果：未校验、已校验、待确认、未找到（旧称“身份状态”） |
| 数据轮次 | 达人资料的来源批次，不一定等于当前审核轮次 |
| 已补全 | 达人资料完整度：粉丝、笔记数、总点赞都已获取 |

界面里的“采集轮次”对应本文第 6 章：一个轮次是一批采集数据，同一轮次每次重新运行都会产生一条新的“运行记录”，统计以最新一次成功运行为准。

### 1.4 角色与权限

系统有“管理员”和“成员”两种角色。所有成员共享同一批轮次、达人、线索和关键词，账号主要用于登录、责任归属、权限控制和操作记录。

| 功能 | 管理员 | 有采集权限的成员 | 无采集权限的成员 |
|---|---|---|---|
| 工作台、达人库、线索库 | 可以 | 可以 | 可以 |
| 新建采集、采集轮次、关键词 | 可以 | 可以 | 不可用 |
| 查看轮次名称、任务、费用 | 可以 | 可以 | 隐藏或脱敏 |
| 达人标注、设置跟进人 | 可以 | 可以 | 可以 |
| 新增/编辑线索 | 可以 | 需线索权限 | 需线索权限 |
| 校验/转换线索 | 可以 | 需采集权限 + 线索权限 | 不可以 |
| 导出数据 | 可以 | 可以 | 可以，但会隐藏轮次相关列 |
| 用户管理、设置 | 可以 | 不可以 | 不可以 |

说明：

- “采集权限”和“线索权限”是两个独立开关，由管理员在用户管理中分别开启。
- 达人“跟进人”是责任标记，不是编辑锁；所有人都可以查看和标注达人。
- 线索“负责人”决定编辑、校验、转换权限；非管理员只能处理自己负责或未分配的线索。

## 2. 登录与账号

### 2.1 登录

1. 使用团队管理员提供的访问地址，在浏览器中打开系统。
2. 输入用户名和密码，点击“登录”。
3. 登录成功后，系统会保持登录状态约 7 天。

系统不支持自助注册。账号由管理员创建；忘记密码请联系管理员重置。

### 2.2 首次登录

管理员创建账号或重置密码后，首次登录会被要求修改密码。

修改步骤：

1. 输入当前密码；
2. 输入新密码并确认；
3. 保存后即可进入系统。

### 2.3 密码规则

- 密码长度至少 8 个字符，最多 200 个字符；
- 修改密码时，新密码不能与当前密码相同；
- 连续登录失败次数过多时，需要等待一段时间再试。

### 2.4 修改密码与退出

点击右上角账号菜单：

- “修改密码”：输入当前密码和新密码；
- “退出登录”：退出当前账号。

修改密码后，该账号在其他设备上的登录会话会失效。

### 2.5 账号与数据共享

- 团队成员看到的是同一套业务数据；
- 账号用于识别操作人、分配跟进人/负责人和记录操作历史；
- 普通成员看不到采集轮次、关键词和系统设置；
- 无采集权限的成员看不到轮次名称、任务进度和费用等敏感信息。

## 4. 工作台

### 4.1 轮次范围

有采集权限的用户可在右上角选择：

- **全部轮次**：只统计未归档轮次；同一达人只显示最近一条轮次的结果；
- **某个轮次**：只统计该轮次中的达人。

无采集权限的成员只能查看全部轮次汇总。

### 4.2 核心指标

| 指标 | 说明 |
|---|---|
| 达人总数 | 当前范围内的达人数量；全部轮次按达人去重 |
| 已补全 | 粉丝、笔记数、总点赞都已获取的达人；补全率 = 已补全 / 达人总数 |
| 已采用 | 审核状态为“已采用”的达人；审核通过率 = 已采用 / 已处理 |
| 线索 | 当前范围内的线索数量，并展示待核实、已转达人数 |
| 总消耗 | 当前范围产生的费用（token）；全部轮次会包含历史轮次和线索校验等消耗 |
| 待处理 | 按当前账号视角，需要处理的待审核和未分配备选达人 |

说明：

- “已处理”指审核状态不是“待审核”的达人；
- “部分完整”的达人不会计入“已补全”；
- 单采用成本 = 总消耗 ÷ 已采用人数，无已采用时不显示。

### 4.3 采集进行中

有采集轮次运行时：

- 顶部显示任务阶段、进度和已处理数量；
- 工作台自动刷新；
- 点击可进入轮次详情。

### 4.4 待处理

“待处理”卡片显示需要你处理的达人数量，点击后进入达人库，并自动筛选：

- 待审核的达人；
- 未分配的备选达人。

列表按“互动/粉丝比”从高到低排序，优先展示潜力更高的达人。

### 4.5 图表

| 图表 | 内容 | 点击作用 |
|---|---|---|
| 采用分布 / 审核进度 | 各采用状态的人数和占比 | 进入达人库并按状态筛选 |
| 粉丝层级 | 达人粉丝量级分布（未补全不计入） | 仅查看 |
| 合作跟进 | 各合作阶段的达人分布 | 进入达人库并按合作状态筛选 |

粉丝层级：

| 层级 | 粉丝数 |
|---|---|
| 顶流 | 100 万及以上 |
| 头部 | 50 万及以上 |
| 腰部 | 10 万及以上 |
| 尾部 | 1 万及以上 |
| 素人 | 少于 1 万 |
| 未补全 | 暂无粉丝数据 |

### 4.6 采集与审核日历

- 展示近一年每日活动热力图；
- 可切换“新增达人”和“审核动作”；
- 颜色越深表示当天数量越多；
- 悬停可查看当天新增达人数和审核动作数；
- 选择某个轮次时，按该轮次统计；选择全部轮次时，按系统内全部历史数据统计；
- 右侧显示累计、活跃天数、活跃日平均、单日峰值和最近 12 周趋势。

## 5. 新建采集

### 5.1 开始前确认

- 当前账号有采集权限；
- 当前平台有可用的数据服务商；
- 关键词库有已启用的关键词，或准备在表单中输入新词。

### 5.2 填写内容

| 字段 | 是否必填 | 说明 |
|---|---|---|
| 已有词库 | 否 | 从已启用关键词中多选 |
| 新增关键词 | 否 | 用逗号、顿号、分号或空格分隔，系统会自动去重 |
| 关键词总数 | 是 | 最多 50 个；单个关键词最多 50 个字符 |
| 平台 | 是 | 选择本次采集的平台 |
| 采集服务商 | 是 | “自动（最便宜可用）”或指定服务商 |
| 每个关键词页数 | 是 | 1–20 页，默认 1 页 |
| 最多补全达人数 | 否 | 1–500 人；留空表示不限制 |
| 垂类 | 是 | 最多 40 个字符，用于轮次归类和统计 |
| 轮次名称 | 否 | 最多 100 个字符；留空自动生成；不能重名 |
| 强制刷新达人资料 | 否 | 开启后忽略已有资料，重新获取，会增加费用 |

### 5.3 服务商与费用

- “自动”会按本轮预估总费用选择可用服务商；
- 页面会显示所选服务商的每次费用、参考人民币价格和本轮预估费用；
- 不同服务商的价格不同，实际扣费以服务商账单为准；
- 页面金额是参考值，实际费用通常会低于预估，因为部分达人资料可能已有缓存。

### 5.4 预算估算

```text
搜索次数 = 关键词数 × 每词页数
补全次数 = 最多补全人数（留空时按 搜索次数 × 10 估算）
预估费用 = 搜索次数 × 搜索单价 + 补全次数 × 资料单价
```

实际费用可能低于预估，因为：

- 已缓存的达人资料不会重复获取；
- 搜索结果可能少于预估上限；
- 服务商可能提前返回空页或结束分页。

### 5.5 创建与启动

1. 点击“创建并开始采集”；
2. 核对关键词、平台/服务商、页数、人数、垂类和预估费用；
3. 确认后系统创建轮次并立即开始采集；
4. 页面自动跳转到轮次详情。

说明：

- 轮次名称不填时，系统会按日期自动编号；
- 同时运行的任务数量有限；如果达到上限，本次创建会失败，需稍后重试；
- 创建后可在轮次详情查看进度、费用和日志。

### 5.6 常见提示

| 提示 | 处理方式 |
|---|---|
| 请至少选择或输入一个关键词 | 选择词库或输入新词 |
| 关键词最多 50 个 / 单个最多 50 个字符 | 精简关键词 |
| 请填写轮次定位 | 填写垂类 |
| 轮次定位最多 40 个字符 | 缩短垂类 |
| 轮次名称最多 100 个字符 | 缩短名称 |
| 页码需在 1 到 20 之间 | 调整页数 |
| 当前平台没有可用的采集服务商 | 联系管理员检查服务商状态和余额 |
| 轮次名称已存在 | 更换名称或留空自动生成 |
| 关键词已停用 | 到关键词页启用该词 |

## 6. 采集轮次

### 6.1 轮次列表

- 按创建时间倒序展示所有未归档轮次；
- 显示轮次名称、关键词、平台/服务商、状态、进度、达人数、花费和用时；
- 运行中的任务会自动刷新；
- 管理员可切换“显示已归档”查看历史归档任务。

### 6.2 轮次详情

| 区域 | 内容 |
|---|---|
| 运行状态 | 状态、阶段、进度、花费、耗时、开始和结束时间 |
| 运行日志 | 最近运行日志，可手动刷新 |
| 最近服务商请求 | 最近请求的状态、服务商、消耗、耗时和错误信息 |
| 采集配置 | 关键词、平台/服务商、垂类、页数、候选达人、关联线索、笔记数 |
| 任务操作 | 重新运行、取消运行 |
| 轮次管理 | 管理员可归档、恢复或永久删除 |

### 6.3 重新采集

| 选项 | 作用 |
|---|---|
| 强制刷新达人资料 | 忽略已有资料，重新获取，会增加费用 |
| 跳过余额检查 | 余额不足或无法查询余额时仍然开始，可能超支 |
| 本次服务商 | 仅影响本次；自动模式会选择当前更优的可用服务商 |

确认框会显示本轮预估费用上限。重跑后统计以最新一次成功运行为准：已审核/已认领达人保留，未审核且本次未命中的采集达人会从轮次移除。若部分搜索页失败，系统会保留原始响应和费用，但不删除旧达人、不推进最新快照，并在任务阶段和通知中提示“保留上一快照”。余额检查只是开始前预检，不是并发任务之间的硬性限额。

### 6.4 取消任务

- 管理员可取消任何进行中的任务；
- 普通成员只能取消自己发起的任务；
- 取消后已产生的数据和费用会保留。

### 6.5 归档与永久删除

**归档**：

- 从默认轮次列表中隐藏；
- 保留全部数据、线索关联、合作记录和附件；
- 可随时恢复；
- 有运行中任务的轮次不能归档，需要先取消或等待结束。

**永久删除（仅管理员）**：

- 删除轮次及其关联数据；
- 需要手动输入完整轮次名称确认；
- 有运行中任务或线索关联时不能删除；
- 删除后不可恢复，请优先使用归档。

### 6.6 运行规则

- 同一轮次同时只能运行一个任务（一条运行记录）；
- 系统可同时运行多个任务，但有总量上限；
- 任务中断或长时间无响应时，系统会自动标记为失败；
- 单个达人获取失败不会立即终止任务，连续失败达到一定次数才会终止；
- 余额不足、账号失效等严重问题会终止任务。

### 6.7 常见失败原因

| 现象 | 原因 | 处理 |
|---|---|---|
| 余额不足 | 服务商余额不足 | 充值或确认后跳过余额检查 |
| 已达并发上限 | 同时运行的任务太多 | 等待其他任务结束 |
| 该轮次已有任务运行 | 同一轮次不能重复运行 | 等待当前任务结束 |
| 所有搜索页都失败 | 服务商异常、余额或网络问题 | 查看任务日志和服务商状态 |
| 服务商不可用 | 服务商凭据或余额异常 | 联系管理员 |
| 任务长时间无进度 | 任务中断或服务异常 | 取消后重新运行 |
| 关键词已停用 | 轮次中的词后来被停用 | 启用关键词后重新运行 |
| 已归档不能运行 | 轮次已归档 | 先恢复轮次 |

## 7. 达人库

### 7.1 查看范围

- **全部轮次**：所有未归档轮次中的达人按账号去重；每位达人显示最近一条轮次的审核状态和样本数据；命中关键词和来源标签合并历史记录；
- **单个轮次**：只显示该轮次的达人；达人资料仍以最新资料为准；
- **平台**：可查看全部平台或单个平台。

无采集权限的成员看不到轮次选择器和“数据轮次”列。

> 在“全部轮次”视图修改采用状态，会修改该达人最近一条轮次的审核结果。要修改指定轮次，请先切换到该轮次。

### 7.2 筛选与排序

| 筛选项 | 说明 |
|---|---|
| 搜索 | 昵称、账号 ID、原始标题、标签、命中关键词、来源标签 |
| 采用状态 | 可多选；全部轮次视图按最近一条轮次筛选 |
| 合作状态 | 可多选；可筛选“未进入” |
| 粉丝层级 | 顶流、头部、腰部、尾部、素人、未补全 |
| 跟进人 | 全部、我跟进的、其他成员、未分配 |
| 排序 | 粉丝数、互动量、样本点赞、样本篇均互动、昵称、合作更新时间 |
| 匹配方向 | 高级筛选，可多选 |
| 命中关键词 | 高级筛选，可多选；支持“任一命中 / 全部命中” |
| 来源标签 | 高级筛选，可多选 |
| 最低/最高粉丝 | 高级筛选，按粉丝数范围 |
| 超过 N 天未跟进 | 高级筛选；只统计未联系、已联系、洽谈中、合作中 |
| 只看未补全 | 只显示资料未完整的达人 |
| 仅看待处理 | 待审核或未分配的备选达人 |

### 7.3 快捷筛选

| 按钮 | 效果 |
|---|---|
| 已采用 · 未联系 | 已采用且尚未联系的达人 |
| 我的待跟进 | 我负责且处于合作进行中的达人 |
| 超期未跟进 | 我负责、合作进行中且超过 7 天没有新记录的达人 |

### 7.4 列表与列

- 每页可选择 25、50、100 或 200 条；
- 默认显示核心列：昵称、粉丝数、粉丝层级、采用状态、合作状态、匹配方向、代表作、笔记数、总点赞、互动量、跟进人；
- 可自定义显示更多列：粉丝（万）、合作更新时间、账号 ID、主页、数据轮次、命中关键词、来源标签、平台、合作主平台、原始标题、样本数据、备注、标签；
- 昵称列始终显示并固定在左侧；
- 列显示设置保存在当前浏览器中。

### 7.5 行内修改

- **采用状态**：点击状态直接修改；未分配达人的首次修改会自动归你跟进；
- **合作状态**：
  - 从未进入合作流程且本轮已采用的达人，可以直接选择合作状态，系统会创建首次合作；
  - 已进入合作流程的达人显示当前状态；
  - 选择“合作完成 / 已拒绝 / 已取消”会二次确认；
  - 未采用且从未进入合作的达人显示“—”。

所有修改都会检查是否有人先修改过；如果数据已变化，系统会提示刷新，不会覆盖他人修改。

### 7.6 选择与批量操作

- 可勾选多个达人，选择可跨页保留；
- “全选本页”只选择当前页；
- **批量跟进**：把所选未分配达人设为你跟进；已被他人跟进的会跳过；
- **批量修改**：
  - 本轮采用状态：仅在选中具体轮次时可用；
  - 合作状态：只支持进行中的状态；
  - 匹配方向、人工标签、备注：可设置新值或清空；
  - 跟进人（管理员）：可转交或设为未分配；
  - 未分配的达人会自动归当前操作人；
  - 有冲突时会汇总提示，不会覆盖他人修改。

### 7.7 跟进人

- 跟进人记录在达人主档，跨轮次共享；
- 只是责任归属，不限制任何人查看或编辑；
- 未分配时，首次保存标注、状态或合作会自动归当前用户；
- 详情中：
  - 未分配：成员可“我来跟进”，管理员可分配给任意成员；
  - 已由我跟进：可转交给其他成员或设为未分配；
  - 已由他人跟进：成员只能查看，管理员可转交或清空；
- 批量“跟进”只处理未分配的达人。

### 7.8 常用字段说明

| 字段 | 说明 |
|---|---|

| 数据轮次 | 达人资料来自哪个批次 |
| 命中关键词 | 该达人被哪些搜索词命中；全部轮次视图合并历史 |

| 匹配方向 | 人工填写的业务方向 |
| 人工标签 | 手工填写的标签，多个用逗号分隔 |
| 代表作 | 样本中点赞最高的一篇笔记 |
| 样本笔记 / 点赞 / 收藏 / 评论 / 互动 | 本轮搜索命中的笔记样本数据 |
| 样本篇均互动 | 样本互动 ÷ 样本笔记 |
| 合作主平台 | 合作主要发生的平台 |
| 资料更新 | 达人资料最近一次获取时间 |

## 9. 合作跟进与证据

### 9.1 合作状态

| 状态 | 含义 | 是否进行中 |
|---|---|---|
| 未联系 | 已采用但尚未联系 | 是 |
| 已联系 | 已发出联系或初步沟通 | 是 |
| 洽谈中 | 报价、形式、排期等洽谈中 | 是 |
| 合作中 | 已确认合作、执行中 | 是 |
| 合作完成 | 已完成交付 | 否 |
| 已拒绝 | 达人/客户拒绝 | 否 |
| 已取消 | 合作取消或搁置 | 否 |

### 9.2 进入合作流程

- 只有至少在一个轮次中被采用过的达人才能进入合作流程；
- 达人从非采用改为“已采用”时，如果从未合作过，系统会自动创建第 1 次合作，状态为“未联系”；
- 后续轮次重新采集不会重置合作状态；
- 合作状态是达人主档，跨轮次共享；
- 已进入过合作流程的达人，后续轮次即使不是“已采用”，仍会显示主档上的合作状态。

### 9.3 合作记录

- 每位达人的每次合作是一条独立记录，序号依次递增；
- 同一时间只能有一个进行中的合作；
- 第一次合作默认从“未联系”开始，后续新合作默认从“已联系”开始；
- 每条合作记录包含：状态、摘要、开始时间、状态更新时间、完成时间、时间线、附件、作品、备注；
- 合作记录会自动把未分配的达人跟进人设为操作人。

### 9.4 更新状态

1. 打开达人详情 → 合作记录；
2. 选择要更新的合作；
3. 点击“更新状态”；
4. 选择新状态，可填写备注并上传附件；
5. 保存后时间线会记录本次变化。

如果记录已被他人更新，系统会提示刷新后重试。

### 9.5 完成合作

- 点击“完成合作”；
- 可填写结案备注、登记作品链接、上传附件；
- 确认后合作状态变为“合作完成”；
- 完成后不能再用“更新状态”修改，但仍可补充备注、附件和作品；
- 已完成但没有登记作品时，系统会提示补充证据。

### 9.6 附件

| 项目 | 规则 |
|---|---|
| 支持类型 | PNG、JPEG、WebP、PDF、TXT、Word、Excel、ZIP |
| 单文件大小 | 不超过 20 MB |
| 分类 | 合同/协议、报价/沟通、截图、结算凭证、其他 |
| 说明 | 可选，最多 500 字 |
| 删除 | 上传者本人或管理员可删除 |
| 查看 | 所有登录用户可下载查看 |

### 9.7 作品链接

- 每条合作可以登记多个作品链接；
- 作品链接必须是 http/https 地址；
- 可以填写平台、标题、发布时间和备注；
- 同一合作下未删除的作品链接不能重复；
- 修改或删除作品会写入合作时间线。

### 9.8 更正状态

- 已结束的合作如状态有误，管理员可以“更正状态”；
- 必须填写更正原因；
- 更正会写入时间线，原记录不会消失。

### 9.9 导出合作档案

- 点击“导出档案”下载 ZIP；
- ZIP 包含合作信息、时间线和附件；
- 适用于合同归档、交付留档和证据留存。

### 9.10 超期未跟进

- 合作处于未联系、已联系、洽谈中或合作中；
- 且最近一次合作记录活动（状态、备注、附件、作品等）已超过 N 天；
- 工作台默认按 7 天统计；
- 达人库可自定义 1–365 天；
- 合作完成、已拒绝、已取消不算超期。

### 9.11 工作台合作指标

| 指标 | 含义 |
|---|---|
| 已进入合作流程 | 合作状态非空的达人 |
| 进行中 | 未联系 + 已联系 + 洽谈中 + 合作中 |
| 超期 | 进行中且超过 N 天没有新的合作记录 |
| 合作中 | 当前处于合作中 |
| 合作完成 | 当前处于合作完成 |
| 已拒绝 / 已取消 | 当前处于对应终止状态 |
| 累计完成次数 | 范围内所有合作记录中已完成的次数 |
| 重复合作人数 | 合作次数大于 1 的达人数 |

## 10. 线索库

### 10.1 线索是什么

线索是还未确认或转化的达人资源，常见来源：

- Excel 导入；
- 手动录入；
- 客户提供；
- 采集发现；
- 其他。

线索与达人库分开管理。线索可以：

- 与本地已有达人自动匹配（不产生费用）；
- 调用服务商校验真实账号（可能产生费用）；
- 转为达人并关联到采集轮次（可能产生费用）。

### 10.2 线索字段

| 字段 | 说明 |
|---|---|
| 昵称 | 线索显示名称 |
| 平台 | 所属平台 |
| 平台账号 | 用户可见账号，如小红书号 |
| 平台用户 ID | 服务商内部账号 ID |
| 主页链接 | 平台主页地址 |
| 原始标题/备注 | 原始线索文本 |
| 来源 | Excel 导入、手动录入、客户提供、采集发现、其他 |
| 来源轮次 | 线索关联的采集轮次，可多个 |
| 负责人 | 线索维护人 |
| 线索状态 | 待核实、核实中、已转达人、重复、已废弃 |
| 身份状态 | 未校验、已校验、待确认、未找到 |
| 匹配达人 | 本地匹配到的达人及匹配方式 |
| 转化达人 | 转化后的达人账号和时间 |

### 10.3 线索状态

| 状态 | 用途 |
|---|---|
| 待核实 | 默认状态，等待确认 |
| 核实中 | 正在核实账号或资料 |
| 已转达人 | 已转化，不能再编辑 |
| 重复 | 与已有线索重复，可改回其他状态 |
| 已废弃 | 不再跟进，可改回其他状态 |

线索列表默认只显示“待核实 + 核实中”；需要查看全部时，请调整线索状态筛选。

### 10.4 身份状态

| 状态 | 含义 |
|---|---|
| 未校验 | 还未校验账号 |
| 已校验 | 账号、主页或用户 ID 与获取结果一致 |
| 待确认 | 获取结果与线索账号不一致，或只有昵称一致 |
| 未找到 | 服务商没有找到该账号 |

### 10.5 线索列表与筛选

- 搜索：昵称、原始标题、账号 ID、平台账号、主页链接、历史导入 ID；
- 平台、轮次（有采集权限时）、线索状态、线索来源、负责人；
- 默认 50 条/页，可选 25/50/100/200；
- 行内显示身份状态、来源、负责人、线索状态和更新时间；
- 已本地匹配达人的线索会显示“已关联达人”；
- 满足条件时显示“转为达人”快捷按钮；
- 支持导出当前筛选结果。

### 10.6 新增线索

入口：线索库 → “新增线索”。

| 字段 | 说明 |
|---|---|
| 平台 | 默认当前平台或小红书 |
| 昵称 | 昵称、平台账号、用户 ID、主页链接至少填写一项 |
| 平台账号 | 小红书号、微博号、抖音号等 |
| 平台用户 ID | 可选 |
| 主页链接 | 可选 |
| 来源 | 默认手动录入 |
| 来源轮次 | 可选；转化为达人时必须至少关联一个未归档轮次 |
| 负责人 | 默认自己 |
| 原始标题/备注 | 可选 |

系统会自动去重：

- 已存在有效线索时，会打开原线索，不重复创建；
- 已存在的线索如果是“重复”或“已废弃”，会恢复为“待核实”；
- 创建后会自动尝试匹配本地达人；匹配失败不影响线索保存。

### 10.7 批量导入线索

入口：线索库 → “批量粘贴”。

支持：

- 直接粘贴文本；
- 上传 CSV 或 TXT 文件（单文件不超过 4.5 MB）。

带表头时，支持这些列名：

```text
平台、昵称、账号、平台账号、用户ID、平台用户ID、主页、主页URL、链接、URL、原始标题、标题
```

无表头时，可以按以下格式：

```text
昵称
昵称,平台账号
昵称,平台账号,原始标题
小红书,昵称,小红书号,https://…
https://…
```

说明：

- 平台可以填平台名称或英文简称，留空使用选择的默认平台；
- 主页链接可以放在任意位置，系统会自动识别；
- 空行和以 `#` 开头的行会被忽略；
- 缺少昵称、账号、用户 ID 和主页链接的行会标记为无效；
- 默认负责人是自己；
- 可以选择默认来源和来源轮次；
- 导入后会逐行提示成功、重复或失败；
- 已成功的行不会因为其他行失败而回滚。

### 10.8 线索详情

点击线索行打开详情，可查看和操作：

- 基础资料；
- 账号校验；
- 转化时是否重新获取资料；
- 来源轮次；
- 负责人；
- 线索状态；
- 已关联达人、匹配轮次和匹配方式；
- 核实记录；
- 身份校验记录；
- 重新匹配；
- 标记重复 / 废弃；
- 转为达人。

权限：

- 管理员可编辑全部未转化线索；
- 有线索权限的成员只能编辑自己负责或未分配的线索；
- 无线索权限时只读；
- 已转达人的线索只读。

### 10.9 自动匹配

- 创建或修改线索、完成一轮采集、手动“重新匹配”时，系统会尝试匹配本地达人；
- 匹配依据：平台用户 ID、平台账号、历史导入 ID；
- 仅匹配本地已有达人，不产生服务商费用；
- 昵称只作为疑似匹配建议，不会自动关联；
- 可以点击“确认关联”采用建议；
- 自动匹配不会改变线索状态。

### 10.10 校验账号

适用人员：管理员或有采集权限且能编辑线索的成员；只能校验自己负责或未分配的线索。

步骤：

1. 填写平台账号、平台用户 ID 或主页链接，至少一项；
2. 选择服务商；
3. 点击“校验账号”；
4. 系统返回：已校验、待确认、未找到或校验失败；
5. 已校验会自动保存；待确认需要人工确认；未找到/失败不会修改线索账号。

费用说明：

- 使用用户 ID 或主页链接校验，通常只产生一次资料费用；
- 只有小红书号时，系统会先按昵称搜索，再获取资料，可能产生“搜索 + 资料”两次费用；
- 如果搜索结果匹配不到小红书号，需要补充主页链接或用户 ID；
- 其他平台只有平台账号时，建议补充用户 ID 或主页链接；
- 校验失败时，界面会显示预估费用，实际失败通常不计费。

### 10.11 转为达人

前提：

- 有采集权限；
- 详情页操作需要线索编辑权限（或管理员）；
- 线索状态为“待核实”或“核实中”；
- 至少关联一个未归档轮次；
- 至少填写平台账号、平台用户 ID、主页链接之一；
- 只能转换自己负责或未分配的线索（管理员不受限）。

两种方式：

1. **复用本地资料**：已关联达人且关闭“转换时抓取最新资料”，直接转为达人，不产生费用；
2. **获取或校验后转换**：系统获取账号资料并校验，可能产生费用；账号不一致时会再次确认。

转换后：

- 线索状态变为“已转达人”；
- 线索资料只读；
- 达人被加入关联的轮次；
- 达人资料更新（如果选择获取）；
- 线索中命中该轮关键词的内容保留为命中关键词，其余保留为来源标签；
- 线索负责人未分配时归当前操作人；
- 系统自动关联本地达人。

### 10.12 快捷转为达人

列表中的快捷按钮需要同时满足：

- 有采集权限；
- 线索未转化；
- 有平台账号、用户 ID 或主页链接；
- 状态为待核实/核实中；
- 负责人为空、是我或我是管理员；
- 有来源轮次或匹配轮次；
- 如果用户 ID 为空，身份状态必须已校验。

遇到账号不一致时，系统会打开线索详情，要求人工确认。

### 10.13 常见问题

| 提示 | 原因 | 处理 |
|---|---|---|
| 仅待核实或核实中的线索可以转为达人 | 线索是重复、废弃或已转 | 调整状态后再转换 |
| 该线索没有关联轮次，无法转为达人 | 未设置来源轮次，也没有匹配轮次 | 在详情中设置来源轮次 |
| 请先校验账号，确认后再转换 | 只有平台账号、没有用户 ID 且未校验 | 先校验，或补主页链接/用户 ID |
| 账号不一致，是否继续 | 获取到的账号与线索不一致 | 核对后确认，或修正账号 |
| 该线索正在转换中 | 另一位同事正在转换 | 等待后重试 |
| 旧线索已恢复为待核实 | 之前标记为重复或废弃 | 正常，可继续跟进 |
| 检测到重复线索 | 历史数据存在重复账号或主页 | 联系团队管理员处理 |

### 10.14 线索与达人的区别

| 维度 | 线索 | 达人 |
|---|---|---|
| 用途 | 待核实、待转化资源 | 已采集或已转化的正式资料 |
| 归属 | 负责人决定编辑权限 | 跟进人只是责任标记 |
| 状态 | 待核实、核实中、已转达人、重复、已废弃 | 参与轮次审核；合作状态在主档 |
| 账号字段 | 平台账号与用户 ID 分开 | 账号 ID 与平台账号分列 |
| 费用 | 校验/转换可能产生费用 | 采集/补全可能产生费用 |

## 14. 自动发件

### 14.1 权限与账号

- 需要管理员在「用户管理」开启「允许自动发件」；管理员默认拥有该权限。
- 个人 SMTP 账号只有本人可见可改；共享账号由管理员维护，所有发件人可使用。
- 首次使用前由运维执行 `codata-admin email-key --init` 生成密钥；密钥丢失后已保存的 SMTP 密码无法解密，只能重新添加账号。
- QQ/163 使用授权码，Gmail 使用应用专用密码；企业邮箱需要确认已开启 SMTP。

### 14.2 新建发件

1. 在「自动发件 → 发件账号」添加并测试 SMTP 账号；「测试连接」只验证连接和认证，编辑账号时的「发送测试」会向指定邮箱真实发送一封测试邮件；
2. 新建发件，选择发件账号，填写主题和纯文本正文；
3. 正文支持变量：`{{nickname}}`、`{{platform}}`、`{{user_id}}`、`{{fans}}`、`{{profile_url}}`，未知变量会在提交前提示并被后端拒绝；
4. 目标池只包含「已采用 + 未联系」的达人；缺邮箱的达人可在列表中直接补充；
5. 设置计划开始、发送时段、星期、间隔、抖动和日上限；
6. 在最终确认中核对发件账号、人数、时段、频率和自动标记设置，再创建并计划。补充邮箱、创建任务、写入收件人和计划发送在同一事务中完成；没有有效收件人时不会留下空草稿或部分邮箱。未提交的页面内容有离开保护。

### 14.3 状态与操作

- 任务状态：草稿、已计划、发送中、已暂停、已完成、已取消；任务详情每 5 秒刷新，收件人分页显示。
- 收件人状态：待发送、发送中、已发送、失败、跳过。
- 暂停/恢复/取消会显示操作结果。暂停会阻止后续领取，已经进入 SMTP 发送阶段的一封仍可能完成；取消后不能恢复。
- 可重试失败收件人：明确的临时失败自动最多尝试 3 次（含首次），人工重试最多 3 次；永久拒收、认证失败和“发送结果未知”不会自动重试。人工重试“状态未知”的邮件前应先向收件人或邮件服务商确认，否则可能重复外联。
- 每封邮件在外发前保存固定 Message-ID，重试沿用同一标识；SMTP 已返回成功后，即使审计或合作状态更新失败，也不会因此自动重发。
- 认证失败会自动暂停任务并标记账号，更新密码并测试成功后可在账号页一键恢复关联任务。修改 SMTP 主机、端口、加密方式、用户名、密码或发件邮箱会使旧测试状态失效。
- 已被任何任务使用的发件账号不能删除，只能停用；修改合作状态、退订或活动防重规则会在发送前再次校验。
- 发送成功后可选自动把合作状态从「未联系」改为「已联系」；失败不会改状态。
- 同一达人只能保留在一个未结束任务的待发送/发送中列表中；重复收件人会跳过并记录原因。
- 同一邮箱默认 30 天、同一达人默认 90 天内不重复发送；目标池会显示“冷却中”，发送前还会再次校验。
- 发件账号可设置最小发送间隔，多个任务共用账号时取任务间隔与账号间隔的较大值。
- 配置 `CODATA_PUBLIC_URL` 后，邮件会自动追加退订链接并发送 `List-Unsubscribe` / `List-Unsubscribe-Post` 头；收件人点击后进入确认页，确认即写入退订名单并跳过待发邮件。未配置时只能通过“回复退订”联系发件人。
- 退订名单由管理员在账号页维护；名单内邮箱不会进入目标池，发送前还会再次校验。
- 任务页会显示 worker 心跳/最近错误；心跳超时说明 `codata-web` 未运行或 worker 卡住。

### 14.4 注意

- 只会确认邮件服务器已接收，不追踪打开率或退信；当前没有配置 inbound 服务凭据，不会自动处理退信，退信处理需要额外接入 IMAP 或邮件服务 API。
- 发送任务由 `codata-web`（或统一的 `codata panel`）进程内的单实例 worker 执行，不要同时启动多个实例。
- 日志位于 `data/logs/email_worker.log`，单文件达到 5 MiB 后轮转，最多保留 5 个历史文件。

## 16. 常见问题

### 16.1 登录与账号

**Q：忘记了密码怎么办？**
A：联系团队管理员重置。重置后下次登录需要修改密码。

**Q：提示“请先修改初始密码”？**
A：首次登录或被重置密码后，需要先修改密码。

**Q：为什么登录失败次数过多会被限制？**
A：系统会在一段时间内限制连续失败次数，等待一段时间后再试。

**Q：为什么看不到采集轮次、关键词或设置？**
A：当前账号没有对应权限；请联系管理员开通采集权限或使用管理员账号。

### 16.2 采集

**Q：新建采集提示没有可用服务商？**
A：当前平台没有可用的数据服务商，请联系管理员检查服务商状态和余额。

**Q：为什么实际费用比预估低？**
A：预估按上限计算；已有资料的达人不会重复获取，搜索结果也可能少于上限。

**Q：任务失败提示余额不足？**
A：联系管理员充值或确认余额。确认余额充足后，可以在轮次详情选择“跳过余额检查”重试。

**Q：任务为什么不能同时运行多个？**
A：同一轮次同时只能运行一个任务，系统也有同时运行任务数量上限。

**Q：为什么不能删除某个轮次？**
A：轮次有运行中的任务或关联线索时不能永久删除；建议使用归档。

**Q：轮次名称为什么是日期编号？**
A：新建时未填写名称，系统按日期自动生成；可以自定义名称，但不能重名。

### 16.3 达人库

**Q：全部轮次和单轮次数字为什么不同？**
A：全部轮次按达人去重并取最近一条轮次；单轮只统计该轮次。

**Q：部分完整的达人为什么不算已补全？**
A：已补全要求粉丝、笔记数、总点赞都存在，缺少任意一项都算部分完整。

**Q：修改状态后为什么自动变成我的跟进？**
A：未分配达人的首次标注、状态或合作修改会自动归当前操作人；跟进人只是责任标记。

**Q：为什么其他人也能编辑我跟进的达人？**
A：跟进人不限制编辑；所有成员都可以查看和标注达人。

**Q：如何修改历史轮次的状态？**
A：切换到对应轮次后再修改；全部轮次视图修改的是达人最近一条轮次。

**Q：合作状态为什么显示在非采用达人上？**
A：合作状态是达人主档，跨轮次共享；进入过合作流程的达人会持续显示主档状态。

### 16.4 合作

**Q：为什么不能开始合作？**
A：达人必须至少在一个轮次中被采用过；已采用但从未合作时，系统通常会自动创建首次合作。

**Q：为什么不能开启下一次合作？**
A：同一时间只能有一个进行中的合作；请先完成、拒绝或取消当前合作。

**Q：合作完成后还能补充内容吗？**
A：可以补充备注、附件和作品，但不能直接修改状态；状态有误请联系管理员更正。

**Q：附件支持哪些格式？**
A：支持 PNG、JPEG、WebP、PDF、TXT、Word、Excel 和 ZIP，单文件不超过 20 MB。

### 16.5 线索

**Q：为什么默认看不到全部线索？**
A：线索库默认显示待核实和核实中；调整线索状态筛选即可查看全部。

**Q：为什么“转为达人”按钮是灰的？**
A：请检查采集权限、线索状态、账号/主页、关联轮次、负责人和账号校验状态。

**Q：只有小红书号怎么办？**
A：可以在线索详情点击“校验账号”，系统会先按昵称搜索；也可以补充主页链接或用户 ID。

**Q：提示“仅昵称一致”？**
A：说明账号置信度不足；核对获取到的主页和账号后确认，或修正线索账号。

**Q：提示“账号不一致”？**
A：获取到的账号与线索账号不同；确认是同一人后再转换，否则取消并修正账号。

**Q：为什么线索不能转换？**
A：线索必须关联至少一个未归档轮次，且状态为待核实/核实中。

**Q：负责人和跟进人有什么区别？**
A：线索负责人决定编辑/校验/转换权限；达人跟进人只是责任标记，不限制编辑。

### 16.6 导出

**Q：导出的 CSV 中文乱码怎么办？**
A：系统导出的 CSV 已按 Excel 兼容格式处理；如果仍乱码，请使用 Excel 导出。

**Q：为什么某些单元格前面多了单引号？**
A：这是公式注入防护，避免以 `= + - @` 开头的内容被当作公式执行。

**Q：为什么导出没有数据？**
A：请检查当前筛选条件、状态范围和轮次范围。

### 16.7 自动发件

**Q：为什么邮件里没有退订链接？**
A：需要在 `.env` 配置可公开访问的 `CODATA_PUBLIC_URL` 并重启 `codata-web`；未配置时邮件只能提示收件人回复退订。

**Q：为什么任务被自动暂停？**
A：常见原因是 SMTP 认证失败、账号停用、创建人失去发件权限或密钥不匹配；修正后可在账号页恢复关联任务。

**Q：为什么收件人被跳过？**
A：达人合作状态已变化、邮箱在退订名单、邮箱或达人仍在冷却期，都会在发送前跳过并记录原因。

**Q：worker 正常吗？**
A：任务页顶部显示 worker 心跳；超过 2 分钟没有心跳说明 `codata-web` 未运行或 worker 卡住，查看 `data/logs/email_worker.log`。

## 使用建议

- 每天查看工作台“待处理”，及时审核新达人；
- 每周检查合作进行中的达人和超期未跟进记录；
- 采用达人后及时补充合作备注、合同和作品链接；
- 线索转换前先核对账号，避免转错达人；
- 导出前确认筛选条件和轮次范围；
- 遇到权限、账号、服务商余额或数据异常，联系团队管理员处理。
